# Class Method Call

Select a custom class and method. Non-static methods require an object from **New Class Instance** or another expression. Static methods hide the object input automatically.

Use **Browse Methods…** in the inspector, or double-click the node, to open the two-column Method Browser. Help and examples come from the Markdown **Help information** entered while defining the class method.

Choosing **Use Selected Method** updates the method call and its dynamic ports.

## Building a method chain

Open **Browse Methods / Build Chain…** from a class instance or method call to assemble a linear sequence. The Chain Builder creates normal Class Method Call nodes and object connections, then closes. There is no special saved-chain object; edit each generated node normally or rebuild the sequence when needed.
