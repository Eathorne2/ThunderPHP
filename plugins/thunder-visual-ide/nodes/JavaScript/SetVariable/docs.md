# Set JS Variable

Declares a browser-side JavaScript variable or assigns a new value to an existing variable/property path.

## Assignment modes

- **Declare let** generates `let name = value;`.
- **Declare const** generates `const name = value;`.
- **Declare var** generates `var name = value;`.
- **Assign existing** generates `name = value;` and supports paths such as `app.user.name` or `items[0]`.

The **Variable value** output can be connected to later JavaScript value inputs.
