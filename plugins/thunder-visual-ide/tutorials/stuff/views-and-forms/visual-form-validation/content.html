Build the form in the View

Add a Form component, then place Name and Email inputs inside it. Add a submit button and the CSRF component when your application uses session-based CSRF protection.

Choose a form theme

Select the View node in the main graph and open the Form Theme browser. The theme belongs to the View, so every built-in input uses the same design and palette.

Read and validate submitted data

  1. Open the Controller flow.
  2. Read the visual form data.
  3. Connect it to Validate Form Schema.
  4. Use the rules manager for extra or replacement rules.
  5. Send validation errors back to the View through set_value('errors', ...).

Show errors beside inputs

Each input defaults to the path errors.<field-name>. Choose whether to show the first message or every message.

errors.email
errors.name
Reusable styling

Inline error markup is inserted through the active form theme, so custom themes can control exactly where error messages appear.
