What you will learn

This lesson introduces the main areas of Thunder Visual IDE and explains how they work together to generate a normal ThunderPHP plugin.

  • Use the Node Library and Inspector.
  • Open Controller, View, Model and method graphs.
  • Save a project without needing a database.
  • Preview generated PHP before building a ZIP.

The main architecture graph

The top-level graph describes the plugin itself: routes, controllers, views, models, migrations, assets, permissions and libraries. Double-click nodes with nested graphs to edit their internal execution or View Builder flow.

Tip

Use the panel visibility buttons when you need more canvas space. Returning from a nested graph reselects its owner node.

A safe first workflow

  1. Open File → Browse Samples….
  2. Load a sample and inspect its architecture graph.
  3. Choose Build & Export → Validate Project.
  4. Preview the generated files.
  5. Save the project under your own name before editing.

What the IDE stores

Projects, presets and uploaded library archives are stored locally as files. Use Export All IDE Data ZIP before distributing or replacing the IDE plugin.
