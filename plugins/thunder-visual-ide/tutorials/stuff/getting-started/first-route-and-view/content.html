Goal

Create a plugin page available at /hello-thunder. The Controller will set a title and the View will display it.

1. Add the architecture nodes

  1. Add a Route node and select the GET method.
  2. Set the route name to hello.index and the path to /hello-thunder.
  3. Add a Controller Hook and a View.
  4. Connect the Route to both nodes.

2. Build the Controller flow

Open the Controller graph and use a String node with Hello from Thunder Visual IDE. Connect it to the node that writes a value into page state using the key page_title.

3. Build the View

Open the View Builder and add a container, heading or HTML block. Read page_title using the View variable system.

<h1>{{ page_title }}</h1>

4. Compile and test

Validate first, preview the generated files, then use Deploy Test Plugin if your development installation is safe for local test deployment.

Why connect the Route?

The route connection lets the compiler register the Controller and View callbacks only for that named route.
