This page is a practical companion to the full Thunder CLI and Migration reference. It focuses on short, copy-pasteable tasks you will perform often while working on plugins and database changes.

These recipes assume you are running the CLI tool through the `thunder` command and that your plugin lives inside the `plugins/` folder.

The recipes here are based on the Thunder CLI command list, the migration runner, the migration sample file, the migration tracker, and the base `Migration` class.

Use this page when you want to quickly remember:

- what command to run
- what file gets created
- what to put inside the migration
- what happens when you migrate, rollback, refresh, or check status
