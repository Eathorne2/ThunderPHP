Use this when you want to quickly see the available generators, migration commands, and utility commands.

```php
php thunder help
```

Use this command when:

- you forgot the exact command name
- you want to see supported migration actions
- you want a reminder of generator commands like `make:plugin` or `make:migration`

This is usually the first command to run when getting familiar with the CLI.
