**Get SQL**
- Returns the final query string generated by the builder

```php
$sql = $userModel
    ->where('status', 'active')
    ->toSql();
```

**Get Bindings**
- Returns an array of the data bindings to be used in the query

```php
$bindings = $userModel->getBindings();
```
