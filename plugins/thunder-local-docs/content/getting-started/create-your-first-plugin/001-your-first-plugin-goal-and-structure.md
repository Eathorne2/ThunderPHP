In this guide, you will build a very small plugin that shows a frontend page and an admin page.

The plugin will:

- register routes
- render a frontend page
- render an admin page
- add an admin sidebar link
- demonstrate the basic hook flow

This is the fastest way to understand how ThunderPHP plugins actually work.
