ThunderPHP is available from its GitHub repository:

[github.com/Eathorne2/ThunderPHP](https://github.com/Eathorne2/ThunderPHP)

## Clone with Git

Open a terminal in the folder where you keep development projects, then run:

```bash
git clone https://github.com/Eathorne2/ThunderPHP.git
cd ThunderPHP
```

Cloning with Git makes it easier to pull future framework updates and inspect the project's commit history.

## Download a ZIP file

When Git is not installed:

1. Open the ThunderPHP repository in your browser.
2. Select **Code**.
3. Select **Download ZIP**.
4. Extract the archive into your development folder.
5. Open a terminal inside the extracted ThunderPHP folder.

The terminal should be in the framework root—the folder containing the `thunder` command file—before you run any ThunderPHP CLI commands.
