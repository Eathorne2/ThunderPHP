# Changelog

## 1.2.0

- Redesigned the installed-plugin dashboard and plugin details page.
- Added installed, active, disabled and attention summary cards.
- Added client-side plugin search and active/disabled/issues filters.
- Made installed-plugin cards clickable and keyboard accessible.
- Added health-state messaging and improved quick actions.
- Added safe rendered README documentation with Parsedown support and a bundled fallback renderer.
- Added relative link and image resolution in the fallback README renderer.
- Added README source copying.
- Added section navigation to plugin details.
- Added subtle reveal, hover, loading and navigation animations.
- Added reduced-motion support.
- Added Plugin Manager admin page titles and body class integration.
- Improved tables, forms, alerts, empty states, responsive layout and danger-zone presentation.
