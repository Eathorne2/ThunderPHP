# Thunder Blog image library

Place reusable images inside category folders in this directory. Each immediate
folder becomes a category in the post editor image browser.

Example:

```text
assets/images/library/
├── business/
│   ├── office-team.jpg
│   └── laptop-desk.webp
├── nature/
│   └── forest-path.jpg
└── people/
    └── portrait.png
```

Supported file types: JPEG, PNG, WebP, GIF and SVG. Keep filenames descriptive;
the browser converts hyphens and underscores into readable image names.
